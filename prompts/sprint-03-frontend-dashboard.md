# Codex Prompt: Sprint 03 — Frontend Web Dashboard & Real-Time Monitoring UI

## Роль:
Ты — Senior Frontend Engineer (React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, WebSockets).

## Контекст проекта:
Веб-приложение **Telegram Tools**. Бэкенд на FastAPI предоставляет REST API и WebSockets для MTProto мониторинга чатов.
Задача данного спринта — создать стильный, темный, реактивный веб-интерфейс дашборда.

---

## Задачи реализации:

### 1. Компоненты навигации и макета (`frontend/src/`):
- `components/Navbar.tsx`:
  - Логотип с бейджем «Userbot MTProto».
  - Вкладки: **Правила и триггеры**, **Живой монитор**, **Диалоги и чаты**, **Telegram аккаунт**, **Настройки**.
  - Индикатор WebSocket соединения в реальном времени (`Live` пульсирующий зеленый / `Offline` желтый).
  - Бейдж текущего активного Telegram-аккаунта (имя / телефон).
  - Кнопка выхода из панели.
- `components/Modal.tsx`:
  - Переиспользуемое модальное окно с анимацией открытия, закрытием по `Esc` и клику на бэкдроп.

### 2. Конструктор правил (`pages/RulesPage.tsx`):
- Карточки существующих правил:
  - Быстрый тумблер включения/паузы правила.
  - Список ключевых слов (теги) и минус-слов (красные теги).
  - Отображение источников (`Все чаты` или кол-во) и целевого чата.
  - Кнопки редактирования и удаления.
- Модальное окно создания / редактирования правила:
  - Название и описание.
  - Интерактивный ввод тегов триггер-слов (по нажатию `Enter` или запятой).
  - Интерактивный ввод минус-слов.
  - Выбор режима: `ANY`, `ALL`, `REGEX`, `EXACT`.
  - Чекбокс учета регистра (Case-sensitive).
  - Поля ID исходных чатов и ID целевого чата.
  - Выбор типа действия (`Переслать отчет`, `Автоответ`, `Отчет + Ответ`, `Webhook`).
  - Настройка текста автоответа, задержки в секундах и кулдауна.

### 3. Живой монитор и история (`pages/LogsPage.tsx`):
- Real-time лента:
  - Автоматическое добавление новых входящих сообщений через WebSocket без перезагрузки страницы.
  - **Интеллектуальная подсветка ключевых слов** в тексте сообщения желтым бэйджем.
  - Прямая кликабельная ссылка на сообщение в Telegram (`Перейти к сообщению`).
  - Отображение автора, username, названия чата и времени.
  - Статус доставки уведомления (`Уведомление отправлено`, `Ошибка`).
- Фильтрация и поиск:
  - Полнотекстовый поиск по сообщению, автору или чату.
  - Фильтр по правилам (Dropdown).
  - Пагинация и кнопка «Очистить историю».

### 4. Обозреватель диалогов (`pages/ChatsPage.tsx`):
- Список всех диалогов аккаунта:
  - Карточки с иконками типа чата (Канал, Супергруппа, Группа, ЛС, Бот).
  - Бейджи `Владелец` / `Админ`.
  - Отображение ID чата с кнопкой «Копировать ID» в 1 клик.
- Поиск по названию / username и фильтрация по типам чатов.

### 5. Авторизация Telegram MTProto (`pages/AuthPage.tsx`):
- Пошаговый Wizard:
  1. Шаг 1: Ввод номера телефона (+ международный код).
  2. Шаг 2: Ввод кода подтверждения из Telegram.
  3. Шаг 3: Ввод 2FA пароля (если включен).
- Карточка активного аккаунта:
  - Имя, телефон, `@username`, ID, кнопка отключения аккаунта.

### 6. Настройки и безопасность (`pages/SettingsPage.tsx`):
- Информация о версии и хранилище базы (`/app/data`).
- Смена мастер-пароля веб-интерфейса.

## Требования к качеству кода:
- Строгая типизация TypeScript (`strict: true`).
- Чистая темная тема в фирменном стиле Telegram (`#0E1621`, `#17212B`, `#24A1DE`).
- Успешная компиляция `npm run build` (`tsc && vite build`).
